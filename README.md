# Manual Testing Portfolio

## About This Project

This repository demonstrates my beginner-level manual software testing skills through test case design, test scenario preparation, and bug report documentation.

I created this project as part of my learning journey toward an entry-level Software Tester / Junior QA Tester role.

## Project Objectives

- Understand and document login functionality.
- Design positive and negative test cases.
- Practice identifying potential defects.
- Learn to document issues clearly and systematically.

## Testing Scope

- Login functionality
- Input field validation
- Empty field validation
- Invalid credential handling
- Password masking
- Logout functionality

## Testing Approach

- Review the expected functionality.
- Prepare test scenarios and test cases.
- Execute tests on a suitable practice application.
- Compare actual results with expected results.
- Document and report confirmed defects.
